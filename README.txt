SISTEMA DE REQUISICIONES · TERRAZA CHALCO
Paquete listo para publicar como sitio estático en Vercel.

PUBLICACIÓN EN VERCEL (desde iPhone o computadora)
1. Entra a https://vercel.com e inicia sesión.
2. Crea un proyecto nuevo y elige la opción para desplegar un proyecto estático (o importa un repositorio Git).
3. Sube/conecta el contenido de esta carpeta como raíz del proyecto.
4. No configures framework ni comando de build. Deja el directorio de salida como la raíz (.).
5. Pulsa Deploy. Vercel generará un enlace HTTPS.

USO EN IPHONE
1. Abre el enlace HTTPS en Chrome para iPhone.
2. Usa la aplicación desde esa pestaña. Si quieres, también puedes agregar el sitio a la pantalla de inicio desde el menú Compartir de iOS.

USO EN ANDROID
1. Abre el enlace HTTPS en Chrome.
2. Desde el menú de Chrome puedes elegir Instalar aplicación o Añadir a pantalla de inicio, si aparece.

DATOS Y PRIVACIDAD
- Los datos se guardan localmente en cada dispositivo/navegador.
- No hay cuentas, base de datos ni sincronización automática entre dispositivos.
- El modo sin conexión se activa después de la primera visita correcta al enlace.
- Usa la función de respaldo/exportación de la aplicación para transferir datos manualmente.

NOTA
Este paquete prepara el sitio para Vercel, pero no lo publica en una cuenta Vercel. Para publicar, el propietario debe iniciar sesión y autorizar el despliegue.
